# 界面导览

Hidan Club 采用「常驻侧边栏 + 主工作区 + 底部音乐条」的原生 macOS 布局。本文按真实界面逐区导览，帮助你在第一次打开应用后快速定位每个功能。

## 整体布局

```text
┌────────────┬──────────────────────────────────────┐
│            │                                      │
│  品牌区     │           主工作区                    │
│  ──────    │   （训练台 / 动作库 / 视频库 / …）      │
│  侧边栏     │                                      │
│  导航分组   │                                      │
│            │                                      │
│            ├──────────────────────────────────────┤
│            │           底部音乐条                   │
└────────────┴──────────────────────────────────────┘
```

侧边栏顶部是品牌区：低重心街舞姿态的舞者剪影 Logo（暖白剪影、深墨紫底 `#252248`、脚边荧光绿短线提示节拍），下方是 hidan 名称文字。Logo 从应用包内资源加载，同时用于 Dock 图标与设置页。

## 侧边栏导航

| 入口 | 内容 |
| --- | --- |
| 训练台 | 当前练习内容、画面布局和跟练控制；支持无示范的摄像头自由练习 |
| 动作库 | 三个分类：3D 示范（AIST++）、基本功（16 张文字卡）、我的动作（视频导入的二维片段） |
| 编排库 | 多片段编排：AIST 三维片段编排与「视频动作编排」列表（含缩略图、片段明细、来源说明与「练习这套」） |
| 视频库 | 导入的原视频与训练台录像，支持肢体识别、分段与发布 |
| 音乐库 | 原创八拍（各自记住 BPM）与导入后永久保存的本地音乐，两种播放器样式 |
| 一起跳 | P2P 好友连线：开房间／加入房间、共享选项与节拍同步 |
| 历史 | 训练记录：真实流程时长、计满段落、跳过事件 |
| 资源 | 研究资源入口与数据目录访问 |

> **内容选择在训练台之外**：动作库选择单个片段或风格训练计划，编排库选择一套真实片段编排，点击进入训练台后携带原来的模型。训练台本身只显示当前练习内容与跟练控制，不做内容挑选。

## 训练台主工作区

第一屏突出今日目标、当前段落、大号倒计时和开始／暂停按钮。训练台提供四种画面布局：

1. **并排** —— 左侧当前动作模型，右侧摄像头实时画面
2. **只看示范** —— 训练与示范播放状态保留，只改变画面布局
3. **只看摄像头** —— 同上，用于专注观察自己
4. **叠加** —— 摄像头背景上显示半透明动作模型，可调整大小、透明度和拖动位置；3D 示范会隐藏舞台表面、保留人物照明

底部音乐条就是「一起跳」的共享节拍来源：房主的播放、暂停与速度会镜像给客人。

## 3D 动作库界面

3D 目录提供动作名／舞种检索、收藏、逐帧查看、A–B 与八拍区间选择、连续片段导出，以及将选定片段加入训练计划。舞台上方是三张样式卡：

- **柔光人形**（默认）：连续胸腰／骨盆曲面、头颈、渐变粗细四肢、手掌与鞋形脚端，浅色摄影棚与柔光
- **霓虹人形**：同一立体人体，紫青色材质和深色舞台
- **经典骨架**：17 个 COCO 节点、19 条连接、左右双色与参考网格

样式选择保存在本机；切换外观不重新选择动作，也不重置当前帧、A–B、倍速、播放状态或用户视角。原始／官方优化坐标用独立的「坐标来源」控件切换。

## 播放器与时间显示

- UI 帧数从 1 开始显示；导出 JSON 明确 `frameIndexBase: 0`
- 视频模型播放器显示 PTS（如 `20/600`）与秒数，逐帧推进，设备延迟时播放变慢而不跳帧追赶
- A–B 循环、镜像、慢放用于核对捕捉结果
- 动作库播放器与训练播放器相互独立：查看别的动作不会替换训练片段

## 深浅色与窗口

深色窗口布局经过实际检查；正式窗口的分段选择和 BPM 输入框由系统控件绘制。应用为原生 SwiftUI 界面，视频播放使用窄范围 `NSViewRepresentable` 包装的系统 `AVPlayerView`（规避 SwiftUI `VideoPlayer` 在本机触发的 AVKit 元数据 SIGABRT）。

> **提示**：训练台摄像头入口默认可见，首次点击启用时才请求 macOS 相机权限；首次搜索或开「一起跳」房间时 macOS 会请求本地网络权限。
