# 产品概览与理念

Hidan Club 是一款基于 SwiftUI 的**本地街舞学习应用**：在训练台对照动作示范录制自己的练习，在视频库保存原视频、识别二维身体动作，整理成动作或编排后跟练。当前版本 **0.5**，运行于 macOS 14 以上，采用 Swift 6 工具链（Swift 5 语言模式）构建。

> **一句话定位**：帮助个人持续练习、理解动作并回看证据的原生街舞学习工具——不依赖任何第三方包、云端密钥或下载模型。

## 设计哲学：本地优先

Hidan Club 的每一条设计决策都围绕「本地优先（Local-first）」展开：

| 原则 | 具体含义 |
| --- | --- |
| 无第三方依赖 | 只用 Apple 系统框架：SwiftUI、AVFoundation、Vision、SceneKit、VideoToolbox、Network.framework |
| 无云端账户 | 没有登录、没有服务器、没有数据库服务，所有分析在本机进行 |
| 数据不出机器 | 视频、动作模型、音乐、训练历史全部保存在本机应用支持目录 |
| 原始数据保真 | 完整原始帧、原始 PTS 时间戳与置信度全部保留，损坏记录不静默覆盖 |
| 证据可回溯 | 每个动作副本记录来源身份与哈希，导入导出可逐位校验 |

这个定位来自对现有学习产品的调研：与其以课程数量或泛化到所有街舞的 AI 评分竞争，Hidan Club 的差异化是**个人动作档案、完整时间戳观察、节拍练习、可解释的训练安排与本地隐私**。

## 核心学习闭环

产品优先完成一条完整的学习闭环，而不是先训练一个大型模型：

1. **选择目标** —— 从动作库或训练计划确定今天练什么
2. **看示范** —— AIST++ 真实 3D 动作、三种人形样式、逐帧与慢放
3. **分解与慢练** —— A–B 区间循环、八拍切片、¼×～2× 倍速
4. **跟拍** —— 原创八拍节拍或导入音乐，动作按 BPM 倍数跟随
5. **回看** —— 摄像头录像自动入库，与原视频、骨架并排核对
6. **记录感受** —— 训练历史保存真实流程时长与完成段落
7. **下次复习** —— 历史与偏好重启后恢复

> **克制的 AI 承诺**：AI 可以估计身体关键点，但单目骨架不是重心、接触力或舞感真值。应用不把骨架置信度包装成「动作完成度 92%」，也不把生成视频当作可模仿的教学动作。

## 能力全景

| 模块 | 状态 | 说明 |
| --- | --- | --- |
| 统一动作库 | 已实现 | 「3D 示范」观察与片段跟练；「基本功」16 张原创文字卡；「我的动作」保存从视频导入的二维动作片段 |
| AIST++ 3D 动作库 | 已实现 | 完整 1,408 条序列、1,123,873 个独立时间帧、10 个舞种，全帧 Float64 无损保留 |

## 明确不做什么

诚实划定边界与实现功能同样重要。当前版本**未包含**：

- 授权教学视频（文字卡待教师审核）
- 自动舞步分类、舞蹈评分、自由生成三维编舞
- MusicKit / Apple Music 集成（受开发者协议 3.3.6(D) 约束，需另行设计）
- 「一起跳」的 NAT 穿透、中继服务器、多人房间、语音通话或 3D 示范同步
- 崩溃恢复、历史版本迁移、跨设备冲突处理

## 隐私承诺

- 所有肢体识别、节拍估计、分段分析都在**本机**完成，画面不上传
- 「一起跳」不经过任何服务器，不保存、不录音，对方画面只在内存中解码显示
- 录像不含麦克风音轨，不含示范或骨架叠加
- 离开训练台、系统睡眠和退出应用会关闭摄像头并清除当前画面

详细的数据存放位置与隔离机制见[数据与隐私](data-privacy)。

## 技术底座速览

| 技术 | 用途 |
| --- | --- |
| SwiftUI | 全部界面，SwiftUI 应用层与 Foundation-only 的 `HidanCore` 分离 |
| Apple Vision | 视频与实时摄像头的 2D 人体关节检测 |
| AVFoundation | 视频解码播放、摄像头采集、AVAudioEngine 原创节拍合成 |
| SceneKit | AIST++ 3D 动作渲染，柔光人形／霓虹人形／经典骨架三种样式 |
| VideoToolbox | 「一起跳」H.264 硬件编解码（640 或 960 宽） |
| Network.framework | Bonjour 服务广播／发现与 TLS 1.2 预共享密钥加密直连 |

深入实现细节见[架构与技术实现](architecture)。
