# 验证记录摘要

Hidan Club 的每一轮功能都附有可复现的验证记录（`docs/VERIFICATION.md`）。本文按版本摘要关键结果与证据边界。验证环境：Apple Silicon Mac、macOS 26、Swift 6.3.3；部署目标 macOS 14，Swift 5 语言模式。

## 验证方法学

- 本机 Command Line Tools 缺少 XCTest：直接 `swift test` 报 `no such module 'XCTest'`，因此**从不声称 XCTest 套件已运行通过**；测试文件完整保留
- `script/test.sh` 仅对这一具体缺依赖启用独立行为探针，其他错误仍失败
- 探针使用隔离数据目录与合成数据，验证软件合同；不冒充真实硬件或真人舞蹈验证
- 离屏渲染 PNG 已逐张查看；系统控件在离屏图中是占位色，不当作真实窗口外观
