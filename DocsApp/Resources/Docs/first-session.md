# 第一次训练：15 分钟上手

本文给出第一次打开 Hidan Club 后的推荐路径。不需要任何账户或网络，唯一可选的前置是安装 AIST++ 数据（见[数据接入全解](aist-dataset)）。

## 第 1 步 · 启动与授权（1 分钟）

1. 运行 `./script/build_and_run.sh` 或双击 `dist/HidanClub.app`
2. 首次点击训练台的摄像头入口时，macOS 会请求**相机权限**——允许后才能实时跟练；只看不练可以拒绝
3. 首次使用「一起跳」搜索或开房间时，macOS 会请求**本地网络权限**

> **提示**：离开训练台、系统睡眠和退出应用会自动关闭摄像头并清除当前画面。

## 第 2 步 · 逛一逛 3D 示范（3 分钟）

1. 侧边栏进入**动作库 → 3D 示范**：可见 1,408 条序列、1,123,873 帧的全量目录
2. 搜索一个动作名试试，例如 `Running Man`（返回 12 条结果），选择 `gMH_sBM_cAll_d22_mMH0_ch09`
3. 切换舞台上方的三张样式卡：柔光人形 / 霓虹人形 / 经典骨架
4. 拖动时间轴逐帧观察，设定 A–B 区间循环播放，或用八拍区间切片
5. 用「坐标来源」控件在**原始**与**官方优化**两层数据间切换——优化层是官方施加时间平滑和约束的结果

## 第 3 步 · 生成第一个训练计划（2 分钟）

1. 选择一种训练风格与时长（10 / 15 / 20 / 30 / 45 分钟）
2. 应用按透明规则生成计划：约 1/6 热身、约 1/10 放松并设上限，其余为基础动作与短休息；较长计划末尾加入熟悉动作自由连接
3. 四个训练风格各含 3 个真实命名的 AIST++ 示范动作，每个练习段都有自己的序列 ID、连续帧范围、坐标层和播放速度
4. 热身和休息段会显示**下一动作预告**，不把舞蹈示范冒充热身指导

## 第 4 步 · 开始跟练（5 分钟）

1. 点击**开始**：大号倒计时运行，示范播放联动
2. 打开摄像头，选择画面布局：
   - **并排**：左示范右自己，第一次推荐
   - **叠加**：半透明人形覆盖在相机画面上，可调大小、透明度、拖动位置；这是手动视觉对照，没有相机标定或人体尺度自动对齐
3. 观察反馈：身体是否入镜、是否多人、当前关节可见性、二维肘膝投影角度
4. **暂停**时间不计入流程时长；**跳段**不把剩余时间计为完成
5. 想录下来就点「开始录像」，练完点「停止并保存」——录像自动进视频库（不含麦克风声音、不含骨架叠加）

## 第 5 步 · 音乐与速度（2 分钟）

1. 底部音乐条选择一套**原创八拍**，用 BPM 滑杆调速
2. 或到音乐库导入本地音乐：应用在本机估计一个整体 BPM，可手改
3. 动作按 ¼× / ½× / 1× / 2× 跟随「曲目 BPM × 播放速度 × 倍数」，限制在 0.25–2 倍
4. 注意：估计不找第一拍、不跟随中途变速——这只对齐速度，不对齐第一拍

## 第 6 步 · 回看与记录（2 分钟）

1. 结束后训练历史自动保存：真实流程时长（含计划内休息、不含暂停）、计满段数、跳过事件
2. 到**视频库**回看刚才的录像，可开肢体识别逐帧提取关节，核对捕捉结果
3. 历史 UI 做四舍五入／向上取整显示，与原始数据表达区分
