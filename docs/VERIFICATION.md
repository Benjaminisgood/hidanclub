## 核心行为

本机 Command Line Tools 缺少 XCTest：直接 `swift test` 报 `no such module 'XCTest'`，因此不能声称 XCTest 套件已运行通过。测试文件完整保留；`script/test.sh` 仅对此具体缺依赖启用独立验证，其他错误仍失败。

`script/test.sh` 实际退出 0。Foundation-only 探针通过 15,108 项检查，包括 288 组时长/舞种/等级组合、总时长精确、先修次序、输入边界、序列规则与计时状态转换。

主要行为：

- 暂停时间不计入流程时长；恢复后接着计时。
- 跳段不把剩余时间或被跳过段计为完成；迟到的 tick 跨段补算，超出终点的时间不计入。
- session ID 稳定，完成记录去重；只在已开始且已结束时提供历史。
- 10–45 分钟方案精确合计；包含热身、休息与放松，先修动作顺序有效。
- 四组八拍规则组合检查输入、站立低冲击条件，并给 BPM/先修/风格警示。

## 视频姿态与逐帧数据

独立 `script/qa_pose_probe.swift` 使用自己生成的 VFR 空白视频，未下载素材、未访问摄像头。通过：

- 原始 8 帧全部保留；PTS 与输入 `[0,1,3,4,7,8,12,15]/30` 对应一致。
- 无人帧完整保留，coverage = 0；导出 JSON 可 round-trip。
- 8 种标准旋转/镜像的方向映射与非标准变换拒绝。
- 取消不发布部分报告；旧任务不能覆盖新任务；无效源返回明确错误。

上面验证了软件的数据处理契约。方向映射的单元检查不等于所有实际旋转媒体均已实拍验证。**没有用真实舞者视频评估关键点准确度**，也没有训练舞步分类器、验证评分或生成三维舞蹈。

## 媒体播放

`qa_music_probe.swift` 在实际 AVAudioEngine 上静音运行，覆盖：原创节拍、暂停时间线保留、恢复、BPM 修改继续播放、非法 BPM 归一化、stop 重置、44.1 kHz 单声道 / 48 kHz 立体声切换、多次文件循环和切回原创。

短测试音频的 pre-mixer tap 在起音后没有全空 buffer。该检查不证明所有压缩格式的循环拼接都 sample-perfect，也不是听感验证。

`qa_video_probe.swift` 独立编译运行通过：真实加载/时长、暂停时精确 seek、0.5×与恢复速度、全片 A–B 循环两次、暂停不复播、错误源处理。另显式注入延迟结束通知，重现并修复 pause/end-event race；该部分是确定性并发测试，不能伪称是自然媒体自动产生的事件。

以上两个媒体探针可通过 `./script/test_media.sh` 重跑。需要可用 macOS 音频输出设备，但默认测试输出静音。

## 持久化

- 实际启动、暂停、结束，保留真实短时长与 0/16 个计满段落。
