上面验证了软件的数据处理契约。方向映射的单元检查不等于所有实际旋转媒体均已实拍验证。**没有用真实舞者视频评估关键点准确度**，也没有训练舞步分类器、验证评分或生成三维舞蹈。

## 媒体播放

`qa_music_probe.swift` 在实际 AVAudioEngine 上静音运行，覆盖：原创节拍、暂停时间线保留、恢复、BPM 修改继续播放、非法 BPM 归一化、stop 重置、44.1 kHz 单声道 / 48 kHz 立体声切换、多次文件循环和切回原创。

短测试音频的 pre-mixer tap 在起音后没有全空 buffer。该检查不证明所有压缩格式的循环拼接都 sample-perfect，也不是听感验证。

`qa_video_probe.swift` 独立编译运行通过：真实加载/时长、暂停时精确 seek、0.5×与恢复速度、全片 A–B 循环两次、暂停不复播、错误源处理。另显式注入延迟结束通知，重现并修复 pause/end-event race；该部分是确定性并发测试，不能伪称是自然媒体自动产生的事件。

以上两个媒体探针可通过 `./script/test_media.sh` 重跑。需要可用 macOS 音频输出设备，但默认测试输出静音。

## 持久化

`script/qa_store.sh` 实际退出 0，所有文件使用临时 `HIDAN_DATA_DIR`，未访问用户历史：

- 实际启动、暂停、结束，保留真实短时长与 0/16 个计满段落。
- 多次重新实例恢复相同 UUID 的一条记录，无重复。
- 损坏 JSON 原始字节在读取、训练结束和重试后保持一致，自动保存阻断。
- 人为阻塞父目录导致写失败，内存记录仍保留；解除阻塞后显式重试成功写入并清除错误，重开可恢复。

正常退出会结束并保存当前训练。崩溃/强制终止恢复、迁移历史版本、跨设备冲突处理尚未实现。
