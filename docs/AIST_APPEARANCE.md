# AIST++ 动作外观

3D 动作库提供三种外观，点击舞台上方的样式卡切换：

- **柔光人形**：默认样式，连续胸腰/骨盆曲面、头颈、渐变粗细四肢、手掌与鞋形脚端，搭配浅色摄影棚和柔光。
- **霓虹人形**：同一立体人体，紫青色材质和深色舞台。
- **经典骨架**：保留原来的 17 个 COCO 节点、19 条连接、左右双色与参考网格。

人形样式可叠加原骨架、显示关节名称和参考网格。样式选择保存在本机；切换外观不重新选择动作，也不重置当前帧、A–B、倍速、播放状态或用户视角。切换原始/官方优化坐标仍使用独立的“坐标来源”控件。

## 数据与外观的区别

人体表面是本项目构造的风格化外观，直接由当前帧关键点驱动。胸腰曲面和手脚朝向使用有限关节点作显示估计，体型、手掌、鞋形脚端不代表测量得到的额外关节或真实舞者外貌。缺少支持点的部位隐藏，不通过插值补帧。原始 Float64 坐标、完整帧序列和导出内容不变。

官网演示使用 SMPL 表面人体，需要另一套完整姿态与人体模板。当前人形不是已复现 SMPL，也没有将限制分发的人体模型权重打包到应用。现有连续片段导出仍是来源关键点；不会把示意人体顶点写成测量数据。

舞台圆盘、灯光与地面只是显示参考。它们不会将源数据重新贴地或改变舞者的垂直位移。播放沿用原来的全帧顺序，未加入时序平滑。

验证范围见 [VERIFICATION.md](VERIFICATION.md)，回归脚本为 `script/qa_aist_appearance.sh`。
